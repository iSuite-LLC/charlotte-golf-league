# Golf League Website Design Spec
**Date:** 2026-04-29
**Project:** 2026 IMI Golf League — Live Standings Website

---

## Goal

Replace the static `Dashboard/standings.md` file with a live website hosted on GitHub Pages. The site auto-updates within ~30 seconds of every score push, with no extra steps in the existing workflow.

---

## Approach: JSON Data File + Static HTML/JS Site

`process_scores.py` is extended to write `Dashboard/data.json` on every run. A single `Dashboard/index.html` fetches that JSON and renders the full site client-side with vanilla JavaScript. GitHub Pages serves the `Dashboard/` folder. No frameworks, no build step, no backend.

`standings.md` is kept as-is — the Claude score-update workflow does not change.

---

## Site Structure

Single-page application with three tabs.

### Standings Tab (default)
- Header shows current round + status badge ("Round 1 in progress")
- League table columns: Rank, Player, Total Pts, Record (W-L-D), Avg NET
- Clicking any player row expands an inline panel with round-by-round breakdown: opponent, match points scored, NET score, result (W/L/D)
- BYE players shown as a distinct muted row with a "BYE" badge
- Players with no rounds played yet shown below ranked players

### Results Tab
- Rounds listed most-recent-first
- Each round is a collapsible section: round number, dates, BYE player
- Inside each round: all matches listed as "Player A (X pts) vs Player B (Y pts)" with winner bold
- Rounds not yet played shown as "Upcoming" with dates only

### Schedule Tab
- Full 9-round season calendar: Round, Dates, BYE
- Current round highlighted with orange indicator
- Completed rounds marked with a checkmark

## Visual Design

### Color Palette (IMI sports-dark theme)
| Token | Hex | Usage |
|-------|-----|-------|
| Background | `#111111` | Page background |
| Surface | `#1e1e1e` | Cards, panels, table rows |
| Text primary | `#ffffff` | All main text |
| Text muted | `#888888` | Secondary info, losses |
| IMI Red | `#cc2027` | Wins, 1st place badge |
| IMI Blue | `#1a6fc4` | Active tab, links |
| IMI Green | `#5aaa35` | Draws, positive stats |
| IMI Orange | `#e87722` | Current round badge, rank highlights |
| Gold | `#e87722` | 1st place rank |
| Silver | `#aaaaaa` | 2nd place rank |
| Bronze | `#cd7f32` | 3rd place rank |

### Layout
- Fixed header: "IMI Golf League 2026" + "Last Updated: [date]" right-aligned
- Tab bar below header: Standings / Results / Schedule
- Full-width content area; responsive (stacks on mobile)

### Standings Table Details
- Rank badge colored: gold (1st), silver (2nd), bronze (3rd), plain for rest
- Record shown as colored spans: W in red, D in green, L in muted gray
- Expanded player panel: dark inset background, round rows with result color coding
- BYE row: muted, "BYE" orange badge, no pts/record shown

### Results Details
- Round header bar in IMI orange
- Winner: bold white; loser: muted gray
- Match pts shown in parentheses: `Ethan High (6) def. Brian Wojcio (2)`

## Build Pipeline Changes

### `process_scores.py` extension
After writing the main workbook, call a new `write_dashboard_json(round_data)` function that:
1. Reads all player data from `Scores 2026` tab (all rounds completed so far)
2. Reads match pairings from the round's score tab (to build the `matches` array)
3. Writes `Dashboard/data.json`

### Commit workflow (unchanged)
```
Scores entered → process_scores.py runs → Excel updated + data.json written
→ Claude updates standings.md
→ git add Dashboard/standings.md Dashboard/data.json setup/process_scores.py
→ git commit + push → GitHub Pages live in ~30s
```
